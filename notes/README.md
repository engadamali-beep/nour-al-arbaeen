# ملاحظاتي 📝

تطبيق ملاحظات عربي احترافي (RTL) يعمل **بالكامل داخل المتصفح**، بلا خادم وبلا قاعدة بيانات سحابية:

- **قاعدة بيانات محلية حقيقية** باستخدام IndexedDB — كل شيء يبقى على جهازك.
- **حساب مستقل لكل مستخدم** بالبريد الإلكتروني وكلمة المرور، وعزل كامل بين الحسابات.
- **تشفير من طرف المتصفح**: محتوى كل ملاحظة مشفّر بـ **AES-256-GCM**، ومفتاح التشفير مشتق من كلمة المرور عبر **PBKDF2-SHA-256** (210,000 دورة).
- **يعمل دون إنترنت** وقابل للتثبيت كتطبيق (PWA).
- واجهة عربية أنيقة مع الوضعين الفاتح والداكن، وبحث فوري، ووسوم، وألوان، وأرشيف، وسلة مهملات.

> **الرابط المباشر:** <https://engadamali-beep.github.io/nour-al-arbaeen/>

## كيف يعمل؟

GitHub Pages يقدّم **ملفات ثابتة فقط** ولا يشغّل Node.js أو قواعد بيانات. لذلك بُني التطبيق على نمط **Local-first**:

| الطبقة | التقنية |
|---|---|
| قاعدة البيانات | IndexedDB داخل المتصفح (`malhazati`) |
| الحسابات | سجل مستخدم محلي + مُتحقِّق كلمة مرور PBKDF2 |
| تشفير الملاحظات | AES-256-GCM بمفتاح مشتق من كلمة المرور |
| الجلسة | `sessionStorage` — تبقى مع تحديث الصفحة وتنتهي بإغلاق التبويب أو القفل |
| العمل دون إنترنت | Service Worker + Manifest |

### ماذا يعني ذلك عمليًا؟

- لكل **جهاز/متصفح** قاعدة بياناته المستقلة. الحساب الذي تنشئه هنا لا يظهر تلقائيًا على جهاز آخر.
- لا يوجد خادم يستقبل بياناتك، ولا يتم رفع الملاحظات إلى الإنترنت.
- كلمة المرور **لا تُخزَّن أبدًا**؛ يُخزَّن فقط مُتحقِّق مشتق منها. لذلك **لا توجد استعادة لكلمة المرور**، ولا يمكن فك تشفير الملاحظات بدونها.
- لنقل بياناتك إلى جهاز آخر استخدم **الإعدادات ← تنزيل نسخة احتياطية**، ثم **استيراد نسخة** على الجهاز الجديد بعد إنشاء حساب هناك.
- النسخة الاحتياطية ملف JSON يحتوي ملاحظاتك **كنص مقروء**، فاحفظه في مكان آمن.

## الميزات

- إنشاء وتعديل الملاحظات مع **حفظ تلقائي** أثناء الكتابة.
- تثبيت الملاحظات المهمة في المقدمة.
- أرشفة الملاحظات واستعادتها.
- سلة مهملات مع استعادة أو حذف نهائي.
- بحث فوري في العناوين والمحتوى والوسوم ( يتجاهل التشكيل وفروق الهمزات والتاء المربوطة).
- وسوم ملوّنة تلقائيًا + تصفية حسب الوسم.
- ستة ألوان للملاحظات.
- عرض شبكي أو قائمة، وترتيب حسب آخر تعديل أو تاريخ الإنشاء أو العنوان.
- إحصاءات سريعة: الملاحظات النشطة، المثبتة، الوسوم، وعدد الكلمات.
- وضع فاتح/داكن/تلقائي حسب النظام.
- نسخ احتياطي واستيراد.
- إدارة الحساب: قفل التطبيق، حذف كل الملاحظات، حذف الحساب نهائيًا.
- اختصارات لوحة المفاتيح: `N` لملاحظة جديدة، `Ctrl/⌘ + K` للبحث، `Esc` للإغلاق.

## التشغيل محليًا

يجب تقديم الملفات عبر HTTP وليس `file://`، لأن IndexedDB والتشفير يحتاجان أصلًا آمنًا (`localhost` يُعدّ آمنًا).

```powershell
# من جذر المستودع — أي طريقة متاحة لديك:
python -m http.server 8080 --directory notes/public
# أو
npx serve notes/public
```

ثم افتح: <http://localhost:8080>

أو استخدم إضافة **Live Server** في VS Code على مجلد `notes/public`.

## النشر على GitHub Pages

يوجد Workflow جاهز ينشر مجلد `notes/public` تلقائيًا عند أي تعديل على `notes/**`:

```
.github/workflows/deploy-notes.yml
```

خطوات التفعيل مرة واحدة:

1. ارفع التغييرات إلى الفرع `main`.
2. من المستودع: **Settings ← Pages ← Build and deployment ← Source = GitHub Actions**.
3. انتظر انتهاء التشغيل في تبويب **Actions**، ثم افتح الرابط المنشور.

## بنية مجلد `notes/public`

| الملف | الدور |
|---|---|
| `index.html` | الواجهة الكاملة (RTL، مكتبة أيقونات SVG داخلية) |
| `styles.css` | نظام التصميم، الوضعان الفاتح والداكن، التجاوب |
| `app.js` | منطق التطبيق: الحسابات، العرض، المحرر، البحث، الإعدادات |
| `db.js` | IndexedDB + PBKDF2 + AES-GCM وإدارة الملاحظات |
| `sw.js` | عامل الخدمة للعمل دون إنترنت |
| `manifest.webmanifest` | بيانات تثبيت التطبيق |
| `icon.svg` + `icon-*.png` | أيقونات التطبيق |

> ملفات `notes/server.js` و`notes/db.js` و`notes/package.json` هي محاولة خادم قديمة **غير مستخدمة** بواسطة الواجهة الحالية. التطبيق المنشور يعمل بالكامل من `notes/public` دون أي خادم.

## الخصوصية والأمان

- الاتصال بـ GitHub Pages يخدم الملفات الثابتة فقط (HTML/CSS/JS)، ولا تُرسل أي ملاحظة إلى الخادم.
- محتوى الملاحظات مشفّر قبل كتابته في IndexedDB، والمفتاح لا يُخزَّن على القرص؛ يُحفظ في `sessionStorage` للتبويب الحالي فقط.
- العزل بين المستخدمين مطبّق على مستوى قاعدة البيانات (كل سجل ملاحظة مرتبط بمعرّف المستخدم) وعلى مستوى التشفير (مفتاح مستقل لكل حساب).
- لا يمكن استرجاع البيانات إذا نسيت كلمة المرور. هذا مقصود لحماية خصوصيتك.
