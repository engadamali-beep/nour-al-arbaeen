# ملاحظاتي — تطبيق الملاحظات الشخصية 📝

تطبيق ويب احترافي لملاحظات الشخص (اسم الموقع: **ملاحظاتي** / My Notes) مبني على:

- **قاعدة بيانات SQLite محلية** (ملف `notes/data/notes.db`) — البيانات موجودة على الخادم المحلي وتُحفظ محليًا ولا تُستضاف على أي سحابة خارجية.
- **تسجيل الدخول بالبريد الإلكتروني وكلمة المرور** — كل مستخدم له مساحة ملاحظاته الخاصة.
- واجهة **عربية كاملة (RTL)** بتصميم احترافي حديث.

## التشغيل محليًا

```bash
cd notes
npm install
npm start
```

ثم افتح المتصفح: <http://localhost:3000>

- قاعدة البيانات: `notes/data/notes.db` (يُنشأ تلقائيًا عند أول تشغيل).
- من الأفضّل تشغيل `npm run dev` أثناء التطوير.

## الميزات

- ✅ إنشاء / تعديل / حذف ملاحظات.
- 📌 تثبيت / إلغاء تثبيت الملاحظات.
- 🗃 مؤرشفة الملاحظات (استعادة أو حذف نهائي).
- 🔍 بحث فوري + فلاتر (كل الملاحظات / المثبتة / المؤرشفة).
- 🎨 ألوان مخصصة للملاحظات.
- 🌙 وضع ليلي.
- 🔢 عدّاد الأحرف والكلمات.

## واجهة API

| الطريقة | المسار | الوصف |
|---|---|---|
| POST | /api/auth/register | إنشاء حساب `{name,email,password}` |
| POST | /api/auth/login | تسجيل الدخول `{email,password}` |
| POST | /api/auth/logout | إنهاء الجلسة (Bearer token) |
| GET | /api/auth/me | بيانات المستخدم الحالي |
| GET | /api/notes | قائمة ملاحظات المستخدم (غير مؤرشفة) |
| GET | /api/notes/archived | الملاحظات المؤرشفة |
| POST | /api/notes | إنشاء ملاحظة `{title,content,color,pinned,archived}` |
| PUT | /api/notes/:id | تعديل ملاحظة |
| DELETE | /api/notes/:id | حذف ملاحظة |

الحقول المرجعية: `Authorization: Bearer <token>`.

## النشر على GitHub Pages

هذا المستودع يحتوي على workflow نشر تلقائي على GitHub Pages من مجلد `notes/public`:

- `.github/workflows/deploy-notes.yml`

ملاحظة: **GitHub Pages يقدّم الملفات الثابتة فقط** ولا يمكنه تشغيل خادم Node مع قاعدة بيانات. الاستخدام الكامل (تسجيل حسابات + قاعدة بيانات محلية) يتم عبر تشغيل خادم `notes/server.js` محليًا. النشر على GitHub Pages مخصص لتقديم الواجهة.

## ملاحظة

- كلمة المرور تُخزّن بصيغة مشفرة (bcrypt) ولا تُخزّن بصريّة.
- الجلسات تُحفظ على الخادم وتنتهي تلقائيًا بعد 7 أيام.
